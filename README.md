# Android Lab 08 - Practica de Codigo

Octavo laboratorio de Android. Ejercicios de codigo orientados a patrones de diseno, manejo eficiente de datos y componentes de UI avanzados.

## Temas cubiertos
- Patrones de diseno aplicados a Android
- Manejo y validacion de formularios
- Componentes de UI de Material Design
- Buenas practicas de organizacion de codigo
